# TechSoc Technical Assessment

A responsive React + TypeScript replica of specific pages of the official UST Technovation Society website (`usttechsoc.org`) for a technical assessment.

## Quick Start (Windows)
Double-click `start.bat` in the root folder. It will:
1. Automatically run `npm install` if dependencies are missing.
2. Launch the Vite local dev server at `http://localhost:3000`.
3. Open the website automatically in your default web browser.

## Manual Start (Cross-platform)
```bash
npm install
npm run dev
